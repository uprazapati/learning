# learning
## Sites

Published with GitHub Pages from `docs/`.

- `docs/index.html`: landing page. `docs/assets/` holds the theme picker and space background that both pages share.
- `docs/ddia/`: Designing Data-Intensive Applications reading notes. Each note is a standalone file under `docs/ddia/notes/<chapter>/`.

To add a note, drop the file in the chapter folder and add one entry (`title` and `file`) to the chapter in `docs/ddia/notes.json`. The sidebar and list build themselves from that file.
